# 词栖 · 界面设计规范（可直接交给 AI 使用）

这份文件描述词栖系列项目要遵守的外观与交互规范。新项目请把本文件一并交给 AI，并要求它按此实现。

## 一、总体原则

1. 统一质感：所有可见容器（卡片、底栏、侧栏、对话框、列表行、输入框）必须是同一套"表面"组件渲染，不允许个别区域直接用底色硬写死颜色。
2. 主次分明：背景可以有背景图/壁纸，但正文与图标永远保持完全不透明、可读性优先。
3. 克制的装饰：只用圆角、细边框、轻微模糊来表达质感；不要使用渐变堆叠、粗阴影、花哨描边。
4. 一个页面只有一种强调色，强调色由主题色（accent）统一驱动，不自造第二种颜色。
5. 动画只用淡入淡出或 160–250ms 的位移/缩放，避免弹跳、旋转等让人分心的效果。

## 二、颜色与主题

- 采用 Material 3，`ColorScheme.fromSeed(seedColor: 主题色)`。
- 主题色提供预设色板，并允许用户输入自定义 HEX；默认强调色保持品牌绿。
- 必须同时支持浅色 / 深色 / 跟随系统。
- 语义色（成功、错误、提示）只用于状态，不用来装饰。
- 深色模式下卡片不是纯黑，而是略亮的深灰绿；文字不使用纯白，使用略暖的浅色。

## 三、表面材质（Surface）

所有容器统一由一个共享表面组件渲染，参数包含：是否玻璃质感、表面不透明度。

- 实色模式：单个带圆角的 `Material`，填充 `surface` 色。
- 玻璃模式：圆角裁剪 + `BackdropFilter` 模糊 + 半透明填充。
- 表面不透明度滑杆只改变填充透明度，绝不改变文字/图标透明度。
- 圆角：卡片 20，悬浮底栏默认 24（可调 0–48），输入框 12，按钮 14。
- 边框：1px，取 `dividerColor` 的 10%–15% 透明度。
- 阴影：默认无（elevation 0），靠边框和底色区分层次。
- 列表行也是表面组件，不能直接用裸 `Card`。

## 四、背景与壁纸

- 允许用户选择本地图片作为背景，但图片必须复制进应用私有目录，不能引用外部路径。
- 图片与内容之间必须有一层半透明遮罩，保证任何壁纸下文字都可读。
- 背景图片不透明度可调（0–100%），拖动时实时预览，松手才落盘保存。
- 支持 PNG / JPEG / WebP；限制 10MB、1600 万像素以内，超出时给出明确原因（多大、建议怎么压缩）。
- 图片文件缺失或损坏时静默回退到纯色背景，不能导致启动失败。

## 五、导航

- 宽屏用侧栏，窄屏用底栏；用户可切换为"悬浮底栏"。
- 悬浮底栏：两侧留白（0–48）与圆角（0–48）可调。
- 悬浮底栏不使用选中态椭圆内圈（大圆角下会很难看），只用图标与文字颜色标记当前页。
- 键盘/输入法弹出时自动隐藏底栏，避免遮挡输入。
- 返回键：先回上一级页面；在首页再按一次提示"再按一次返回键退出"，两秒内再按才退出。

## 六、排版

- 中文用系统无衬线（Windows：微软雅黑；若缺失回退系统默认），英文/音标用等宽或几何无衬线。
- 标题 28–32 / 区块标题 18 / 正文 14–16 / 辅助 12–13。
- 行高 1.5–1.8，中文段落偏大。
- 字号比例允许用户调节（0.9–1.3），所有页面在 1.3 倍下仍需可滚动、不溢出。
- 窄屏（390×844）必须逐页验证：所有控件可滚动到达，无 RenderFlex 溢出。

## 七、组件规范

- 卡片：统一表面组件 + 22 内边距（自绘内容时用 0 内边距再自行排版）。
- 按钮：主按钮为填充式，次按钮为描边式，文字按钮仅用于轻量操作；同一区域不超过一个主按钮。
- 开关与选择器：多选题用分段控件（SegmentedButton），开关用 Switch，数值用步进器；同类选项外观必须一致。
- 对话框：圆角、无阴影、标题左对齐；确认与取消固定位置（取消在左）。
- 表单：错误信息用语义错误色，紧贴控件下方。
- 加载：用时短用细进度条，按钮内用圆形进度。

## 八、可访问性与诚实性

- 交互元素最小点击区域 44×44。
- 所有图片背景仅装饰，设 `excludeFromSemantics`。
- 不夸大功能：系统无法保证的行为（精确提醒、开机必达、商店签名）必须在文案中如实说明。
- 颜色对比度：正文与背景至少 4.5:1。

## 九、主题一致性检查清单

新页面/新组件上线前自查：

1. 是否所有容器都走共享表面组件？
2. 玻璃模式与表面不透明度下调时，这个页面是否也生效？
3. 深色、浅色、1.3 倍字号、390×844 四种条件下是否都正常？
4. 强调色改成任意颜色后，是否仍然协调？
5. 有没有硬编码的颜色、圆角、阴影？
6. 有没有自造的第二强调色？
